# 从这里开始

1. 双击 [Python100集学习笔记.html](Python100集学习笔记.html)，侧栏可筛选主题、跳转七天计划和项目。笔记内已包含全部配套代码与真实输出。
2. 每天按 `七天学习路径.md` 学习 3–4 小时；总计 24.5 小时，以基础与项目为主。
3. 按笔记“先运行起来”建立环境；源码在 `代码`，不需要重新下载课程视频。
4. 打开 [代码/project_output/report.html](代码/project_output/report.html) 查看已生成的演示报告；`项目效果.png` 是真实页面截图。
5. `课程目录.csv` 可用表格软件打开。`课程覆盖与来源.json` 保存分集链接、时长和抽样位置；`媒体下载核验.json` 保存下载核验结果。

覆盖链接当前的 100 个分集，不是标题声称的 748 集。整理依据为下载后的画面抽帧 OCR，不是完整语音转录；示例是独立重写，069–071 不包含原 98 题的逐题完整复刻。所有 100 个配套示例已执行成功，项目 5 项测试通过。最终效果使用演示数据，不代表你的真实学习进度。

代码外的构建脚本、原始视频、图片抽帧和原始 OCR 不放入学习材料包。它们不是运行学习示例的依赖。

已按你的偏好将 100 个下载视频及生成的抽帧目录移入系统回收站；未清空回收站。清理记录见 `视频清理记录.json`。
